# Local FEP drafts

These are submission-ready drafts for the Fediverse Enhancement Proposal
repository. They retain the upstream `fep/<slug>/fep-<slug>.md` layout, but are
not registered FEPs until accepted by the FEP facilitators.

Before submission, create the required public discussion, replace the placeholder
`discussionsTo` value, and let the facilitator assign `trackingIssue`.
